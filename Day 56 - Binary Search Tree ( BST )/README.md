# Important Concepts

- Left subtree values must be smaller than the node.
- Right subtree values must be greater than the node.
- Inorder traversal of a BST produces sorted values.
- BST searching and insertion take O(log n) time on average.
- Worst-case time complexity is O(n).
- BST validation takes O(n) time.
