### Day 53 — Linked List Operations

# Topics Covered

- Searching for a value in a linked list
- Inserting a node at the beginning
- Inserting a node at the end
- Counting occurrences of a value
- Inserting a node at a specific position
- Handling negative and out-of-range positions
- Using "ValueError" and "IndexError"
- Traversing linked lists

# Key Concepts

- "head" points to the first node.
- "next" connects one node to another.
- "None" marks the end of the linked list.
- Insertion requires updating node references carefully.
- Returning the updated head is important when inserting at the beginning.

# Time Complexity

- Searching: O(n)
- Insert at beginning: O(1)
- Insert at end without a tail pointer: O(n)
- Count occurrences: O(n)
- Insert at a position: O(n)

Implemented linked list operations using Python classes, loops, conditional statements, and exception handling.
