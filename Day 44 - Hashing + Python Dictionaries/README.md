Key Learnings

- Dictionaries store key-value pairs and help count frequencies.
- Sets store unique elements and support efficient membership checks.
- Hashing can improve lookup performance compared with searching a list repeatedly.
- Two Sum can be solved in average O(n) time using a dictionary or set.
- Frequency dictionaries help identify repeating, non-repeating, and unique numbers.

Complexity Analysis

Operation| Average Time
Dictionary lookup| O(1)
Set membership check| O(1)
Frequency counting| O(n)
Two Sum using hashing| O(n)

Note: These are average-case complexities; individual hash operations can take longer in the worst case.
