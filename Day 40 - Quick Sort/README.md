Practice

- Partition an array using a pivot
- Implement Quick Sort using smaller and greater lists
- Implement in-place Quick Sort
- Sort arrays in ascending order
- Test arrays containing duplicate elements
- Compare Quick Sort with Merge Sort

Time Complexity

- Best Case: O(n log n)
- Average Case: O(n log n)
- Worst Case: O(n²)

Space Complexity

- Average Case: O(log n) auxiliary recursion stack
- Worst Case: O(n) auxiliary recursion stack

Key Learning

Quick Sort selects a pivot, partitions the array around it, and recursively sorts the left and right subarrays. In-place Quick Sort rearranges elements using swaps instead of creating separate lists.
