- Base case and recursive case
- Countdown
- Sum of numbers

- Count digits
- Sum of digits

## What I Learned
I learned how recursive functions call themselves to solve smaller problems. I practiced identifying base cases, reducing problems, and combining recursive results.

## Key Concepts
- Base case stops recursion.
- Recursive case solves a smaller problem.
- `n // 10` removes the last digit.
- `n % 10` extracts the last digit.

I solved multiple recursion problems and practiced dry runs to understand how recursive calls work.
