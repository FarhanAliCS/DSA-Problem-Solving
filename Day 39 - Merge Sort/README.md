### Day 39 — Merge Sort

Topics Covered

Practice Problems

Key Learning

Learned how Merge Sort divides an array into smaller parts, recursively sorts them, and merges them back in sorted order.

Complexity

- Best Case: O(n log n)
- Average Case: O(n log n)
- Worst Case: O(n log n)
- Extra Space: O(n)
