 ### Day 45 — Sets & Hash Set Problems

📚 Topics Covered

- Python sets
- Removing duplicates
- Finding common elements
- Checking whether two lists share elements
- Finding missing elements
- Finding common elements without duplicates
- Comparing unique elements of two lists
- Set union
- Set intersection

🧠 Problems Practiced

1. Remove duplicates from a list.
2. Find common elements between two lists.
3. Check whether two lists have any common element.
4. Find elements in the first list that are missing from the second.
5. Find common elements without duplicates.
6. Check whether two lists contain the same unique elements.
7. Find the union of two lists.
8. Find the intersection of two lists.

🔑 Important Concepts

- Create a set using "set()".
- Add elements using ".add()".
- Check membership using "in".
- Union: "set1 | set2"
- Intersection: "set1 & set2"
- Difference: "set1 - set2"
- Compare sets using "==".

⏱️ Time Complexity

For the set operations practiced today, the average time complexity is generally O(n + m) when processing two lists of lengths "n" and "m". Actual performance can vary in unusual cases.
