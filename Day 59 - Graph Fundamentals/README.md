### Day 59 — Graph Fundamentals

# Topics Covered

# 1. Introduction to Graphs

- Graphs consist of vertices (nodes) and edges.
- A vertex represents an object.
- An edge represents a connection between vertices.

# 2. Types of Graphs

- Undirected Graph: Edges work in both directions.
- Directed Graph: Edges have a specific direction.
- Weighted Graph: Edges contain weights or costs.
- Unweighted Graph: Edges have no weights.

# 3. Graph Terminology

- Vertex
- Edge
- Degree
- Path
- Cycle
- Neighbor
- Connected Graph

# 4. Graph Representations

- Adjacency List
- Adjacency Matrix

# 5. Graph Operations

# Practiced implementing:

- Count vertices.
- Count edges.
- Add a vertex.
- Remove a vertex.
- Add an undirected edge.
- Remove an undirected edge.

# 6. Weighted Graph Operations

- Create a weighted adjacency list.
- Calculate total edge weight.
- Find the weight of a specific edge.
- Update an edge weight.

# 7. Directed Graph Operations

- Add a directed edge.
- Remove a directed edge.
- Prevent duplicate edges.
- Validate vertices and edges.

# Python Concepts Practiced

- Dictionaries
- Lists
- Tuples
- Nested loops
- "enumerate()"
- Conditional statements
- List operations
- Functions
- Graph traversal preparation

# Key Learnings

- Undirected edges are stored in both directions.
- Directed edges are stored only in their specified direction.
- Weighted graphs store neighbor-weight pairs.
- Tuples are immutable, but tuples inside lists can be replaced.
- Removing a vertex requires removing its connected edges first.
