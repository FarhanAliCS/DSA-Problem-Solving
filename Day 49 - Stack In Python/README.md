### Day 49 — Stack in Python

# Topics Covered

- Understanding the Stack data structure
- LIFO (Last In, First Out)
- Push, Pop, Peek, and is_empty operations
- Implementing a stack using a Python list
- Reversing a string using a stack
- Checking balanced parentheses
- Matching parentheses and square brackets
- Handling empty stacks and mismatched brackets

# Key Concepts

Stack: A linear data structure that follows LIFO.

Push: Add an element using "append()".

Pop: Remove and return the top element using "pop()".

Peek: Access the top element using "stack[-1]" without removing it.

Balanced Brackets: Every closing bracket must match the correct opening bracket in the correct order.

# Complexity

- Push: O(1) amortized
- Pop: O(1)
- Peek: O(1)
- Reverse a string using a stack: O(n) time and O(n) extra space
- Balanced brackets: O(n) time and O(n) extra space
